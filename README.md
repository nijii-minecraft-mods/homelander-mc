# Homelander Powers (Fabric 1.21.1)

Серверный Fabric + Polymer мод. Клиентам мод не нужен: предмет и эффект отображаются через Polymer как ванильные, полёт и частицы рассчитываются сервером.

## Возможности

- После питья на 10 минут открываются способности. Максимальное здоровье увеличивается с 20 до 40 единиц, а здоровье полностью восстанавливается.
- Сыворотка кладёт контроллер в первый слот хотбара, сохраняя прежний предмет в инвентаре.
- Обычный клик контроллером включает/выключает красные лучи из глаз. Лучи останавливаются на блоке, дальность — 48 блоков; урона пока нет.
- Shift + клик контроллером переключает полёт с зависанием (как в креативе) и парение (как на элитрах). В режиме парения взгляд задаёт направление, спринт ускоряет.
- Для клиентов достаточно ванильного Minecraft 1.21.1.

Для теста сыворотку можно выдать операторской командой `/give @p homelander:serum`.

## Сборка и установка

Нужна Java 21. Выполни `gradle build`; jar появится в `build/libs/`. На Fabric сервер установи Fabric API и Polymer Core для 1.21.1 вместе с jar этого мода.

## CI/CD и контейнер

`.github/workflows/build-release.yml` собирает мод на каждом push и pull request. Затем CI собирает временный образ Fabric-сервера, запускает его, проверяет загрузку мода, Polymer, Fabric API, `online-mode=false` и Minecraft-протокол. Логи и экспорт контейнера сохраняются как GitHub Actions artifacts.

Push в основную ветку после успешного smoke test публикует тот же проверенный образ в GHCR с тегами `dev-latest` и `build-<run>-<sha>`, а также GitHub Release с JAR без версии в имени, исходниками и `SHA256SUMS.txt`. Публикация пропускается, если на основную ветку уже попал более новый коммит.

Локальная последовательность сборки тестового образа: `./gradlew build`, `./gradlew stageSmokeTestMods`, `python3 scripts/prepare_release.py`, `install -D -m 0644 release-assets/homelander-powers.jar server/mods/homelander-powers.jar`, затем `docker build -t homelander-powers .` и `bash scripts/container-smoke-test.sh homelander-powers`.
