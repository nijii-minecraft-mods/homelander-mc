# Homelander Powers (Fabric 1.21.1)

Серверный Fabric + Polymer мод. Клиентам мод не нужен; сервер предлагает обязательный ресурс-пак с красно-синей колбой: предмет и эффект отображаются через Polymer, лучи — ванильными display-сущностями, парение использует настоящую механику элитр.

## Возможности

- После питья на 10 минут открываются способности. Максимальное здоровье увеличивается с 20 до 40 единиц, а здоровье полностью восстанавливается.
- Сыворотка кладёт контроллер-звезду в первый слот хотбара, сохраняя прежний предмет в инвентаре.
- ПКМ контроллером включает/выключает два сплошных луча: белая сердцевина и красная оболочка, максимальная яркость даже ночью. Лучи поворачиваются за взглядом, останавливаются на блоке, дальность — 48 блоков; живым целям наносится 1 единица урона раз в 0,5 секунды. Это геометрическая имитация луча маяка, не его встроенный рендерер.
- Направление обновляется сразу после принятого пакета взгляда, без интерполяции и доведения. Оболочка медленно вращается вокруг оси луча: оборот примерно за 16 секунд. Сетевая задержка между камерой и сервером остаётся.
- В режиме зависания двойной пробел включает полёт, пробел поднимает, Shift опускает, как в креативе.
- Shift + ПКМ контроллером переключает зависание и парение. Если уже находишься в воздухе, парение начинается сразу с небольшим стартовым ускорением. Если стоишь на земле — прыгни. Нагрудник сохраняется, элитры надевать не нужно; клиент использует физику и горизонтальную позу настоящего элитра-полёта.
- После выбора парения отпусти Shift. Следующее нажатие Shift тормозит и автоматически включает зависание. Полёт также переходит в зависание при остановке, столкновении или завершении парения; при посадке остаёшься на земле. Shift + ПКМ позволяет переключить режим вручную.
- ЛКМ контроллером во время парения даёт повторяемое ускорение по взгляду (до 5 импульсов/с). Мод не ограничивает максимальную скорость; физика элитр, сетевые ограничения и загрузка чанков остаются ванильными.
- Непрерывно грей одну грань горючего блока: листья 2 секунды, брёвна 3 секунды, остальные горючие блоки 2,5 секунды. Затем рядом появляется один обычный огонь. Отведение взгляда сбрасывает нагрев; распространение огня следует правилам Minecraft, при `doFireTick=false` поджиг отключён.
- Для клиентов достаточно ванильного Minecraft 1.21.1.

Предметы называются «Сыворотка Хоумлендера» и «Контроль способностей». Контроллер выдаётся при питье, отдельный крафт ему не нужен.

Крафт одной сыворотки на верстаке:

| Левый слот | Средний слот | Правый слот |
|---|---|---|
| Редстоун | Лазурит | Редстоун |
| Огненный порошок | Звезда Незера | Огненный порошок |
| Золотой слиток | Стеклянная бутылочка | Золотой слиток |

Рецепт открывается после получения звезды Незера. Сыворотка выглядит как колба с красной и синей жидкостью, благодаря серверному ресурспаку.

Для теста сыворотку можно выдать операторской командой `/give @p homelander:serum`.

## Сборка и установка

Нужна Java 21. Выполни `bash ./gradlew --no-daemon test build`; jar появится в `build/libs/`. Сборка включает проверку геометрии луча для всех осей, обратного направления, точек попадания и вращения, а также непрерывного нагрева. На Fabric сервер установи Fabric API и Polymer для 1.21.1 с модулями Core, Resource Pack и AutoHost (например, сборку Polymer bundled) вместе с jar этого мода.

При первом запуске мод создаёт `config/polymer/auto-host.json` с включённой раздачей пакета на порту Minecraft. Уже существующий конфиг сохраняется: в нём включи `enabled=true`, `required=true`, `type="polymer:netty"`. Через прокси/нестандартный внешний порт укажи `settings.forced_address`, например `http://mc.example.org:25565`. При подключении прими пакет; клиентский мод не нужен. Polymer генерирует пакет при запуске сервера.

## CI/CD и контейнер

`.github/workflows/build-release.yml` собирает мод на каждом push и pull request. Затем CI собирает временный образ Fabric-сервера, запускает его, проверяет загрузку мода, Polymer, Fabric API, `online-mode=false` и Minecraft-протокол. Логи и экспорт контейнера сохраняются как GitHub Actions artifacts.

Push в основную ветку после успешного smoke test публикует тот же проверенный образ в GHCR с тегами `dev-latest` и `build-<run>-<sha>`, а также GitHub Release с JAR без версии в имени, исходниками и `SHA256SUMS.txt`. Публикация пропускается, если на основную ветку уже попал более новый коммит.

Локальная последовательность сборки тестового образа: `bash ./gradlew --no-daemon clean test build stageSmokeTestMods`, `python3 scripts/prepare_release.py`, `install -D -m 0644 release-assets/homelander-powers.jar server/mods/homelander-powers.jar`, затем `docker build -t homelander-powers .` и `bash scripts/container-smoke-test.sh homelander-powers`.

Для длительного запуска после подготовки `server/mods` скопируй `.env.example` в `.env` и выполни `docker compose up --build -d`. Мир сохраняется в Docker volume. По умолчанию сервер доступен на `127.0.0.1:25565`; для подключений с других компьютеров выставь `MC_BIND=0.0.0.0`. Логи: `docker compose logs -f`; остановка: `docker compose down`.
